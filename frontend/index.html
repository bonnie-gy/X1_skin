01 / 产品系统

从柔性传感到空间触觉，构成完整交互闭环

产品路线遵循工程可行性优先：先以成熟器件完成系统与商业验证，再逐步引入 MXene/CNT、LIG 与 ZnO 等先进柔性传感材料。

概念验证 PRODUCT 01

FLEXIBLE SENSOR LAYER

X1 Skin

贴合身体曲面的柔性电子皮肤，用于采集压力、拉伸与姿态变化，为触觉反馈提供实时输入。

分布式感知

压力、拉伸与姿态数据按空间位置映射，支持原始数据导出与独立标定。

链式触觉编排

将碰撞、方向和动作事件编码为可定位、可传播、可重复的身体触觉模式。

模块化工程架构

电子层可拆卸、触觉模块可更换、贴肤层可清洗，面向高频 B2B 部署与维护。

    01 / 物料与材料清单

    工程物料与新材料路线

    先用成熟器件完成系统验证，再按可靠性证据逐步导入先进柔性材料。

    阶段材料与器件项目结论
    首代样机TPU 联锁骨架、织物基底、铜 FPC、ERM / LRA立即采用
    局部升级PDMS、AgNW、LIG 传感片、音圈模块模块验证后采用
    联合研发MXene / CNT / TPU、AgNW / 壳聚糖 / ZnO先替换局部节点
